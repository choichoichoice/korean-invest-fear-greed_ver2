# 펭곰이 (Android)

인스타그램·유튜브·틱톡을 **본 시간**을 재고, 아침에 정한 시간(분)을 넘기면 펭곰이가 끼어드는 앱.

## 구조

| 파일 | 하는 일 |
|---|---|
| `UsageWatchService.kt` | 포그라운드 서비스. 시스템 앱 전환 기록으로 대상 앱이 맨 앞에 있는 시간을 1초 단위로 더함 |
| `CounterStore.kt` | 오늘 사용 시간(초)·약속(분)·개입 지점 저장 (폰 안에만). 자정에 어제 기록으로 넘김 |
| `OverlayController.kt` | 다른 앱 위의 카운터 `17분 · 14분 남음`, 펭곰이 한마디, 약속 초과 시트 |
| `MainActivity.kt` | 앱 본 화면. `../scroll-melt/index.html`을 WebView로 띄우고 `PengomNative`로 연결 |
| `Perms.kt` / `BootReceiver.kt` | 권한 확인, 재부팅 후 다시 시작 |

앱 화면은 웹 프로토타입과 같은 파일을 쓴다. 빌드할 때 `scroll-melt/index.html`이 자동으로 복사된다.

## 시간을 재는 기준

- 화면이 켜져 있고, 대상 앱이 맨 앞(포그라운드)일 때만 센다.
- 화면 내용은 읽지 않는다. 어떤 앱이 앞에 왔다/갔다는 기록만 쓴다.
- 서비스가 꺼져 있던 동안의 시간은 다시 켜질 때 오늘 자정부터의 기록으로 다시 계산한다.

## 필요한 권한

1. **사용 정보 접근** (설정에서 직접 허용)
2. **다른 앱 위에 표시** (설정에서 직접 허용)
3. **알림** (Android 13+, 시간 재는 중 표시)

접근성 서비스는 쓰지 않는다.

## 빌드

JDK 17과 Android SDK(플랫폼 34)가 필요하다.

```bash
gradle -p pengom-android assembleDebug
```

결과물: `pengom-android/app/build/outputs/apk/debug/app-debug.apk`

## 폰에서 처음 켤 때

1. APK 설치 (출처를 알 수 없는 앱 허용)
2. 펭곰이 열기 → 아침 약속(분) → "시간 재기 켜기"
3. 사용 정보 접근 → 펭곰이 허용 → 뒤로
4. 다시 "시간 재기 켜기" → 다른 앱 위에 표시 → 펭곰이 허용 → 뒤로
5. 알림 허용
6. 인스타 릴스나 유튜브 쇼츠를 열면 화면 위에 `0분 · 31분 남음`이 뜬다
