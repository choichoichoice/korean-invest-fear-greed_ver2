# 펭곰이 인수인계 (2026-11-19 기준)

다른 컴퓨터에서 이어서 작업할 때 이 문서부터 읽는다. Claude에게 맡길 때도 "pengom-android/HANDOFF.md 읽고 이어서 해줘"로 시작하면 된다.

## 무엇을 만드는가

인스타 릴스·유튜브 쇼츠·틱톡을 **본 시간(분)**을 재고, 아침에 스스로 정한 시간을 넘기면 캐릭터 "펭곰이"가 녹으며 끼어드는 앱.
뼈대는 "듀오링고 + 스크린타임". 핵심 문구는 "네가 정한 거야. 내가 정한 거 아니고."

## 지금까지 정한 것

| 주제 | 결정 | 이유 |
|---|---|---|
| 기준 | **넘긴 횟수가 아니라 시간(분)** | 휙 넘긴 것도 한 번으로 세져서 "얼마나 봤나"의 답이 아님. iOS는 횟수를 셀 수 없음 |
| 예산 숫자 | 사용자가 직접 적음. 5의 배수는 +1 (30 → 31) | 딱 떨어지는 숫자는 "조금 더 봐도 되겠다"는 심리를 부름 |
| 멘트 | 건조하고 짧게 긁는 말투. 말투 단계 설정 없음 | 착한 상담사 말투는 거절됨 |
| 캐릭터 | 사용자가 만든 그림을 레이어로 잘라 움직임 | 코드로 그린 캐릭터는 여러 번 거절됨 |
| 홈 화면 | 키(cm), 기준선, "이번 주 되찾음", 이유 문구는 뺌 | 사용자 피드백 |
| 경쟁 | 브레인롯(아이폰 전용, 시간 기준, 구독 필수)이 가장 가까움 | 안드로이드가 비어 있고 가격 불만이 많음 |
| 마케팅 | 사용자가 직접 맡음 (인스타 대형 계정 운영 경험) | 출시 전에 제작 과정으로 팔로워를 모으는 전략 |

## 다음 할 일: 에뮬레이터 테스트

### 노트북 준비 (Windows / Mac 공통)
1. 코드 받기
   ```bash
   git clone https://github.com/choichoichoice/korean-invest-fear-greed_ver2.git
   ```
   ```bash
   cd korean-invest-fear-greed_ver2
   ```
   ```bash
   git checkout feature/pengom-app
   ```
2. Android Studio 설치 (Java, SDK, 에뮬레이터가 함께 깔림)
3. Android Studio에서 `pengom-android` 폴더 열기 → Gradle 동기화가 끝날 때까지 대기
4. Device Manager → 가상 기기 만들기 → Pixel 계열 → **Google Play가 들어간 API 34 이미지**
5. 실행 ▶

### 확인할 것
1. 앱이 열리고 아침 약속 화면에 펭곰이가 움직이는지
2. 예산을 적고 약속 → 홈에서 "시간 재기 켜기" → 사용 정보 접근, 다른 앱 위에 표시, 알림 권한이 차례로 열리는지
   - 명령어로 한 번에 켜려면:
   ```bash
   adb shell appops set app.pengom GET_USAGE_STATS allow
   ```
   ```bash
   adb shell appops set app.pengom SYSTEM_ALERT_WINDOW allow
   ```
   ```bash
   adb shell pm grant app.pengom android.permission.POST_NOTIFICATIONS
   ```
3. 유튜브 앱에서 쇼츠를 틀면 화면 위에 `0분 · N분 남음` 카운터가 뜨는지
4. 1분마다 숫자가 올라가는지, 예산의 41%·72%·2분 전에 펭곰이 한마디가 뜨는지 (예산을 3분 정도로 작게 잡고 테스트)
5. 예산을 넘기면 "네가 정한 거야" 시트가 뜨고, "나간다"를 누르면 홈 화면으로 가는지
6. 유튜브를 나가면 카운터가 사라지는지, 화면을 끄면 시간이 멈추는지
7. 펭곰이 앱으로 돌아오면 홈 화면 숫자가 맞는지
8. 앱을 강제 종료했다가 다시 열면 시간이 이어지는지

### 알려진 주의점
- `UsageWatchService`는 1초마다 앱 전환 기록을 읽는다. 배터리 사용량을 확인할 것
- 포그라운드 서비스 유형이 `specialUse`라서 플레이스토어 제출 때 사유 설명이 필요함
- target SDK가 34. 플레이스토어 제출 전에 그 시점 요구 버전으로 올려야 함
- 이 저장소는 원래 공포·탐욕 지수 대시보드 프로젝트. 펭곰이는 별도 저장소로 옮기는 게 깔끔함
