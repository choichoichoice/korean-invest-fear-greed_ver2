# 펭곰이 iOS 설계

안드로이드판과 **같은 화면(`scroll-melt/index.html`)과 같은 펭곰이**를 쓰고, "넘긴 횟수"를 얻는 방법만 iOS에 맞게 바꾼다.

## 1. 핵심 결정

| | 안드로이드 | iOS |
|---|---|---|
| 세는 방법 | 접근성 서비스로 넘길 때마다 실측 | 스크린타임 사용 시간 ÷ 22초 = **추정 개수** ("약 37개") |
| 대상 앱 고르기 | 패키지 이름 고정 (인스타, 유튜브, 틱톡) | 사용자가 애플 선택 창에서 직접 고름 (앱 이름은 우리도 볼 수 없음) |
| 중간 한마디 | 화면 위 오버레이 | **알림 배너** (펭곰이 얼굴 + 한 줄) |
| 약속 초과 | 아래에서 올라오는 시트 | **애플 공식 차단 화면**을 펭곰이로 꾸밈 (앱 화면을 실제로 가림) |
| 앱 화면 | WebView + `PengomNative` | WKWebView + 같은 이름의 브리지 |

추정치라는 점은 숨기지 않는다. 숫자 앞에 항상 "약"을 붙인다.

## 2. 쓰는 애플 기능 (전부 무료, 사용량 과금 없음)

| 기능 | 용도 |
|---|---|
| FamilyControls | 스크린타임 접근 권한 (본인 기기용 `.individual`, iOS 16+) |
| FamilyActivityPicker | 사용자가 인스타·유튜브 등을 고르는 애플 기본 선택 창 |
| DeviceActivity | 하루 단위 감시. 정해둔 사용 시간에 도달하면 확장 프로그램을 깨움 |
| ManagedSettings | 고른 앱에 차단 화면 씌우기 / 풀기 |
| ManagedSettingsUI | 차단 화면 꾸미기(펭곰이 그림, 문구, 버튼), 버튼 처리 |
| UserNotifications | 중간 한마디 알림 |
| App Groups | 앱과 확장 프로그램이 약속·기록을 함께 쓰는 저장소 |

**필요한 승인**: `com.apple.developer.family-controls` 권한. 개발 중에는 바로 쓸 수 있지만, **TestFlight·앱스토어 배포용은 애플에 신청해 승인받아야 한다** (무료, 며칠~몇 주). 앱과 확장 프로그램 번들마다 각각 신청.

## 3. 구성

```
pengom-ios/
  project.yml                 XcodeGen 설정 (Xcode 없이도 프로젝트를 글로 관리)
  App/                        본 앱: WKWebView + 브리지 + 앱 선택 창 + 권한 요청
  Shared/                     약속·개입 지점 계산, App Group 저장소 (모든 타깃 공용)
  MonitorExtension/           DeviceActivityMonitor: 시간 도달 시 알림 / 차단
  ShieldConfigExtension/      차단 화면 모양 (펭곰이 녹은 얼굴, 문구, 버튼 이름)
  ShieldActionExtension/      차단 화면 버튼 처리 (나간다 / 그래도 본다)
  ReportExtension/  (2차)     오늘 정확한 사용 시간을 앱 안에 그려서 보여줌
```

## 4. 흐름

### 아침 약속
1. 웹 화면에서 예산을 고른다 (예: 93개).
2. 브리지 `setPromise(93, "운동", th, overTh)` → Shared에서 **개수를 분으로 바꿔** 저장: 93 × 22초 ≈ 34분.
3. 오늘 00:00~23:59 `DeviceActivitySchedule`에 이벤트들을 등록한다.
   - 중간 지점: 웹과 같은 불규칙 지점(41%, 72%, 예산 직전)을 분으로 바꾼 값
   - 촘촘한 진행 이벤트: 3분마다 (홈 화면의 "약 N개"를 갱신하기 위한 용도)
   - 예산 도달 이벤트
   - 초과 지점: 예산 +23, +61, +97…개를 분으로 바꾼 값

### 보는 중 (앱은 꺼져 있어도 됨)
- 진행 이벤트 도달 → MonitorExtension이 App Group에 `usedMinutes` 기록 → 앱을 열면 "약 N개"로 표시
- 중간 지점 도달 → 알림: "약 39개째. 지금 몇 번째인지 모르지?"
- 예산 도달 → 고른 앱에 **차단 화면** 적용 + 알림
- 초과 지점 도달 → 알림: "나 지금 액체임."

### 차단 화면
- 그림: 녹은 펭곰이 얼굴 (`mascot_head_melt`)
- 제목: "네가 정한 거야."
- 부제: "내가 정한 거 아니고. 아침에 쓴 것: 오늘은 운동 하려고 아낀다."
- 주 버튼 **나간다** → 앱 닫기 (`.close`)
- 보조 버튼 **그래도 본다** → 차단을 풀고, 15분짜리 유예 감시를 새로 시작. 15분 뒤 다시 차단. 기록에는 "약속 넘김"으로 남김

### 하루 정산
- `intervalDidEnd`(자정): 예산 이벤트가 울렸는지로 약속을 지켰는지 판정, 어제 추정 개수 저장, 차단 해제
- 앱을 열면 웹 화면의 기존 `nextDay()`가 그대로 돌아 펭곰이가 크거나 녹는다

## 5. 웹 브리지 (안드로이드와 같은 이름)

| 메서드 | iOS 구현 |
|---|---|
| `getState()` | App Group에서 date, count(= usedMinutes×60÷22), budget, history |
| `isCounting()` | FamilyControls 권한 승인 여부 && 고른 앱이 1개 이상 |
| `openAccessibilitySettings()` | 권한 요청 → 승인되면 앱 선택 창 띄우기 |
| `setPromise(...)` | 저장 + 오늘 감시 일정 다시 등록 |
| `openShorts()` | `instagram://reels`, `youtube://` URL로 열기 |

WKWebView는 동기 반환이 안 되므로 `getState`는 네이티브가 `window.__pengomNativeState`에 밀어넣고, 웹은 그 값을 읽는 방식으로 감싼다. 웹 쪽 변경은 작은 어댑터 하나.

## 6. 한계 (사용자에게도 솔직하게)

- **개수는 추정치**: 천천히 보면 많게, 빨리 넘기면 적게 잡힌다. 22초는 설정에서 조정 가능하게.
- **"넘기는 순간"에 끼어들 수 없다**: 알림과 차단은 시간 기준이라 영상 중간에 뜰 수 있다.
- **실시간 숫자 없음**: 홈 화면 숫자는 3분 단위로 갱신된다. 정확한 분은 2차의 ReportExtension으로 보여줄 수 있지만, 그 값은 앱 로직으로 꺼내 쓸 수 없다(애플 개인정보 정책).
- **다이내믹 아일랜드 실시간 갱신은 제외**: 확장 프로그램에서는 갱신할 수 없고, 서버 푸시가 필요해 1차 범위에서 뺀다.
- **확인 필요**: 한 일정에 등록할 수 있는 이벤트 개수 상한, 이벤트가 늦게 울리는 경우가 있다는 개발자 보고. 실기기에서 먼저 확인한다.

## 7. 개발 환경과 비용

- **필수**: Apple Developer Program 연 $99 (TestFlight 포함). 결제는 사용자가 직접.
- **Mac이 없을 때**: GitHub Actions의 macOS 빌드 + XcodeGen + fastlane으로 빌드해서 TestFlight에 자동 업로드. 필요한 것: App Store Connect API 키, 서명 인증서. 개인 저장소 무료 한도 안에서 가능할 것으로 예상(macOS는 시간 10배 차감).
- **스크린타임 API 사용료**: 없음.

## 8. 순서

| 단계 | 내용 | 확인 방법 |
|---|---|---|
| 0 | 개발자 계정 가입, 번들 ID와 App Group 만들기, Family Controls 배포 권한 신청 (기다리는 동안 1~3 진행) | 승인 메일 |
| 1 | XcodeGen 프로젝트 + WKWebView에 기존 화면 + 브리지 | 시뮬레이터에서 화면 표시 |
| 2 | 권한 요청 + 앱 선택 + 하루 감시 + 중간 알림 | 실기기에서 인스타 5분 → 알림 |
| 3 | 차단 화면 꾸미기 + 버튼 처리 + 유예 15분 | 실기기에서 예산 도달 시 차단 |
| 4 | GitHub Actions → TestFlight 자동 업로드 | 내 아이폰 TestFlight에 설치 |
| 5 | 리포트 확장, 홈 화면 위젯 | |

1단계는 Mac이 있어야 시뮬레이터에서 확인할 수 있다. 2~3단계는 스크린타임 특성상 **실기기에서만** 확인할 수 있다.
